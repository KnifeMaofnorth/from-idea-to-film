# 从创意到作品

## AI时代影视创作者的底层逻辑

**作者：马小刀**

镜头都在，作品在哪里？这份文稿讨论如何连接感受、认知、判断与生产组织，把创意完成为能够抵达观众的作品。适合影视创作者、导演、编剧、制片及参与 AI 影像制作的团队阅读。

## 内容结构

1. 判断：什么值得成为一部作品
2. 验证：先做什么，才能知道更多
3. 架构：让所有工作属于同一部作品
4. 调度：把认知、创意与资源组织起来
5. 完成：从局部成果到完整作品
6. 抵达：作品怎样进入真实观看
7. 积累：让每一次创作改善下一次创作

另含引子《镜头都在，作品在哪里？》与结语《让感受抵达另一个人》。文中的“雨夜告别”为设想案例。
